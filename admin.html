Koppelingen

Beide openen in een nieuw tabblad. De voorraad zelf beheer je op de pagina Voorraad.

  • Code GitHub ↗

    De code van de site en de databasemigraties. Een wijziging op de hoofdtak (main) staat daarna vanzelf online via GitHub Pages.

    github.com/JorgVe/Kelderrestjes (opent in een nieuw tabblad)
  • Database Supabase ↗

    De tabellen, gebruikers en de SQL editor van het project kelderrestjes. Supabase vraagt zelf om in te loggen.

    supabase.com/dashboard/project/aspjeliatfudrcjcfidi (opent in een nieuw tabblad)

Monitoring

Wat de site zelf bij Supabase kan opvragen. Gebruik van de server (processor, geheugen, verkeer) staat alleen in het Supabase-dashboard: dat vraagt een persoonlijk toegangstoken, en dat hoort niet in een website.

Databaseversie

Welke updates van de database zijn toegepast (de bestanden in supabase/migrations). Ontbreekt er een, dan werkt het bijbehorende onderdeel van de site nog niet.

    Instellingen

    Schakelaars voor de hele site. Een wijziging staat meteen online en geldt voor alle bezoekers.
